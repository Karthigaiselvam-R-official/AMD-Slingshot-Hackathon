Brief about the idea

Introducing CyberAasaan: The Digital Mentor

Universities face a unique paradox: they must secure thousands of naive users (first-year students) while preserving an open, privacy-first academic environment. Traditional security fails by relying on punitive "hard blocks," confusing IT policies, and invasive telemetry that compromises student data.

CyberAasaan is an edge-native, AI-driven security ecosystem that treats cybersecurity as a continuous educational journey. Powered by local AMD compute, we shift the paradigm from restricting students to actively mentoring them, building a robust roadmap of 4 active phases + 1 future evolution.

1. The Student Edge (Proactive Education)

We transform security from a barrier into a learning tool. CyberAasaan operates as a local AI browser extension, powered by Phi-3-mini and DistilBERT via ONNX Runtime. When a student encounters a phishing link, the AI intercepts it and utilizes the "Teach-Back" LLM to break down the attack's anatomy (e.g., manipulated URLs, psychological urgency) in plain English.

Access to campus portals is secured via frictionless Behavioral Biometrics (typing cadence), seamlessly preventing account takeovers without requiring annoying 2FA prompts.

2. The Institutional Core (Zero-Trust Privacy)

We provide educators and IT staff with rich, campus-wide threat analytics without ever exposing raw Personally Identifiable Information (PII). By pushing AI models to the edge, the behavior models train locally on the student's personal device.

Through Federated Learning and Differential Privacy, only anonymized mathematical weight updates are sent back to the central server. IT gets actionable insights with mathematical proof of rigorous privacy guarantees.

Opportunities & USP

How is it different?

Existing enterprise tools like Cisco Umbrella or Microsoft Defender were built for corporate endpoints, not learners. They hard-block threats without explanation and silently ship telemetry to the cloud. CyberAasaan flips this script. Instead of punishing students who click a bad link, we turn that exact moment into a micro-lesson, educating them in real-time while keeping all raw PII processing on-device.

How does it solve the problem?

Education is the #1 most attacked sector globally, with 74% of breaches involving the human element (Verizon DBIR 2023). We solve this at the root:

  • The Human Fix: The "Teach-Back" AI intercepts phishing and explains the attack anatomy instantly.
  • The Privacy Fix: Federated Learning allows IT to gather critical threat trends without ever exposing raw PII.
  • The Visibility Fix: Our XAI Command Center converts raw logs into plain-English summaries for alert-fatigued admins.

USP — Four Unfair Advantages

The only edge-native ecosystem where protection, education, and compliance happen simultaneously.

  • 1. Pedagogical Security Every blocked threat becomes a personalized teachable moment, not just a dead end.
  • 2. Mathematical Privacy Our ε-differential privacy provides a mathematical proof of anonymity—not just a fragile legal promise.
  • 3. Invisible Authentication Behavioral biometrics add zero friction to the student's day. Security they can't feel is security they can't bypass.
  • 4. Compliant by Architecture FERPA & GDPR compliance isn't bolted on via policies; it's baked into the infrastructure since raw PII physically cannot leave the device.

List of Features

Our solution is deployed across a structured, scalable roadmap of 4 active phases + 1 future evolution:

  • Phase 1: "Teach-Back" Phishing Interceptor. A high-impact browser extension. When a student clicks a fake link, a locally trained model explains the anatomy of the attack (e.g., spoofed domain, fake urgency) instead of just showing a generic error page.
  • Phase 2: Invisible Security Layer. Uses passive Behavioral Biometrics (typing cadence, mouse rhythms) to detect account takeovers without requiring annoying 2FA prompts. Includes a simple "Consent Dashboard" for students.
  • Phase 3: Privacy-Preserving Analytics. A data pipeline utilizing Federated Learning and Differential Privacy. Educators get insights without exposing raw PII.
  • Phase 4: Explainable Command Center. An XAI dashboard for campus IT. It pipes network logs into a local AI to generate plain-language incident reports, eliminating alert fatigue.
  • Phase 5 (Future Evolution): Decentralized Identity. Upgrading Phase 2 to utilize Zero-Knowledge Proofs (ZKP). Students can mathematically prove they are enrolled to access a lab without revealing their name, age, or major.

Technologies Used

Frontend & Student Edge

  • React.js & TailwindCSS: High-performance browser extension UI.
  • Native Messaging API: Securely bridges the React extension to the shared local ONNX inference engine to bypass cloud APIs.

AI & Machine Learning

  • ONNX Runtime with DirectML: Unified inference engine bypassing the cloud. Lightweight models natively target the AMD Ryzen AI NPU, while heavy LLM inference (Phi-3-mini) utilizes AMD Radeon GPUs or integrated graphics via DirectML fallback.
  • Fine-Tuned DistilBERT: NPU-accelerated NLP model trained on PhishTank & OpenPhish datasets for highly accurate, real-time phishing detection.

Privacy Pipeline

  • Flower (flwr): Lightweight framework for Federated Learning. The Python FL microservice is containerized via Docker and communicates with the Node.js backend via a localhost REST API.
  • Opacus (Meta): PyTorch-native library that integrates seamlessly with Flower to inject differential privacy noise on each client device during local training rounds, providing rigorous ε-differential privacy guarantees. Models trained locally with PyTorch + Opacus are exported to ONNX format for efficient edge inference via ONNX Runtime.

Backend & Infrastructure

  • Supabase (PostgreSQL): Scalable backend database managing telemetry limits (leveraging the 500MB storage free-tier limit for MVP).
  • ELK Stack: Serving as the fully open-source SIEM backbone for the IT command center (Production).
  • Node.js / Express: Secure API layer managing telemetry weights.
